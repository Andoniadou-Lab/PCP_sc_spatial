# Balanced 48 pt volcano panels, revision 2

The two volcano plots were redrawn from their source differential-expression tables. All visible text (titles, legend, gene labels, axes, ticks and notes) is **Arial 48 pt**. The page and plot geometry were expanded together so labels appear close to the data points and retain the proportions of the earlier single-panel figures. Fig6 J gene labels are regular weight, as in the original; FigS2 A target labels retain the original bold treatment.

Each PDF is one page and has editable vector points, lines and live embedded Arial text. The source values, significance thresholds, colors and highlighted genes have not changed.

`Fig6_JM_FigS2_15_vector_PDFs_Arial48_balanced_v2.zip` contains these two revised panels and the other 13 previously delivered independent vector panels. The old version and its ZIP remain available in the parent directory.

`Fig6_J_preview.png` and `FigS2_A_preview.png` are render checks of the revised PDFs.
